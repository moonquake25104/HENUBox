# 数据与隐私

HENUBox 是非官方的学习交流项目，无广告，不将本机课表、待办或专注记录主动发送给开发者。账号密码由用户在学校页面输入；服务会话在设备上加密保存。登录页、教务、图书馆、邮箱、全景等学校或第三方服务仍会接收用户主动访问时的必要请求，适用对方政策。

通知、准确提醒和系统勿扰只在用户选择相应功能时申请权限；图库和音频由系统选择器按用户选择读取。背景照片、动画和视频仅作本机展示。应用数据默认不参与系统备份；卸载、清除数据或遗失设备可能导致本地记录丢失。

公开源码不含个人学校账号、Cookie、原始课表、抓包、数据库、运行配置、私有 CA 或签名密钥。不要提交带身份信息的截图、日志或样本；反馈问题前去除姓名、学号、会话和联系方式。软件仍可能存在错误或漏洞，重要安排请核对官方系统；不能把“开源”理解为绝对安全保证。
