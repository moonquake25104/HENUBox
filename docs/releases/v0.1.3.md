# HENUBox v0.1.3

> 把课表、校园服务和日常小事，装进一个盒子里。

## 新增

- **桌面小组件**：专注 2×2、今明课表 4×2、五天课表 4×4、七天课表 4×4；两种周课表可以同时添加，按北京时间显示本周，读取本地课表。三档背景不透明度，默认微透。
- **上课提醒**：按本机课表提前 5/10/15/30 分钟提醒，更新或编辑课表后自动重新安排；保留测试通知和状态反馈。
- **时间与计划**：新增倒计时、倒数日和计划表；首页只展示已经保存的对应内容。
- **本机数据**：待办和专注记录支持 JSON 备份与恢复。
- **关于页**：可以分享公开 Releases 链接。

## 修复与完善

- 修复四种专注模式点击开始后退出页面的问题。
- 课程卡片尽量完整显示教室。
- 校园指南地图与预约进校图片放大时稳定渲染。
- 修正 Android 通知及精确闹钟权限回调、提醒设置和调度。
- 更新检查链接校验、备份恢复和小组件刷新更稳定。

## 安装

- Android 9 及以上，arm64-v8a
- 覆盖安装即可保留本机课表、待办、专注记录和自定义背景
- 非学校官方应用，免费、无广告，不提供学校账号代理

完整功能与参与方式见仓库 [README](../../README.md)。
