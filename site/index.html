河小盒河南大学校园工具

把课表保存在手机，断网也能看。查空闲教室、预约图书馆，再用待办和专注安排好一天。

下载 Android APK GitHub ↗

v0.1.3 · Android 9+ · 免费无广告

一天的安排

从课前提醒到自习结束，常用的事随手就能处理。

离线课表与上课提醒

保存教务课表或手动编辑。支持五天、七天视图，郑州、金明、明伦作息，以及课前 5、10、15 或 30 分钟提醒。

桌面小组件

今明课表、五天课表、七天课表和专注时光都能放到桌面，背景有三档透明度。

校园服务

查空闲教室、打开图书馆预约和邮箱开户。校历、地图、校车和进校预约在校园指南里。

专注与计划

番茄钟、正计时、白噪音和勿扰。用待办、倒计时、倒数日和计划表安排自己的时间。

外观与首页背景

经典、液态玻璃、安卓原生三种风格搭配五套配色。首页可以换成自己的图片或短视频。

本机数据与备份

课表、待办与专注记录保存在设备。待办和专注记录支持导出和恢复，换机前可以自行备份。

安装与使用

  1. 下载 APK

    从本站或 GitHub Releases 下载 Android 安装包。

  2. 在手机上安装

    首次安装按系统提示授权。已有同签名旧版时，可覆盖安装并保留本机数据。

  3. 保存第一张课表

    在学校官方页面完成登录并保存课表，之后断网也能查看。
